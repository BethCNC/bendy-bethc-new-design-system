PageTitle Component

The PageTitle component displays large, prominent page titles using the "Behind The Nineties" display font. It matches the Figma design specifications with proper responsive scaling and design system tokens.

Default PageTitle (Desktop)

Hello Bendy Friends!

Custom PageTitle

About Me

Responsive Behavior

The PageTitle component automatically scales across different screen sizes using responsive design tokens.

Mobile (390px)

Hello Bendy Friends!

Tablet (810px)

Hello Bendy Friends!

Design Tokens Used

The PageTitle component uses the following design system tokens to ensure consistency and maintainability.

Font Family
var(--font-behind-the-nineties)
Font Size (Desktop)
var(--font-size-display-display) - 128px
Font Size (Tablet)
var(--font-size-display-display-tablet) - 72px
Font Size (Mobile)
var(--font-size-display-display-mobile) - 36px
Line Height (Desktop)
var(--line-height-display-display) - 136px
Line Height (Tablet)
var(--line-height-display-display-tablet) - 96px
Line Height (Mobile)
var(--line-height-display-display-mobile) - 48px
Text Color
var(--text-neutral-inverse) - #f9fafa
Background Color
var(--surface-neutral-inverse) - #252626
Padding (Desktop)
var(--spacing-xl) var(--margins-desktop) - 64px 96px
Padding (Tablet)
var(--spacing-xl) var(--margins-tablet) - 64px 64px
Padding (Mobile)
var(--spacing-xl) var(--margins-mobile) - 64px 24px

Usage Examples

The PageTitle component is used consistently across all pages in the application. 

// React Component Usage
import PageTitle from '../components/ui/PageTitle';

// Default title
<PageTitle />

// Custom title
<PageTitle title="About Me" />
<PageTitle title="Contact Me" />
<PageTitle title="Resources" />
<PageTitle title="Links" />
<PageTitle title="Blog" />
